# 🏦 Al-Ameen Bank Project
**A Community-Driven Interest-Free Micro-Banking Solution**

## 🌟 Vision
Helping middle-class families manage their financial needs through a 24/7 digital platform that tracks interest-free loans (up to 50k) and monthly savings without any interest burden.

## 🛠️ Technology Stack
- **Backend:** Python (Flask)
- **Database:** Supabase Cloud (PostgreSQL)
- **Frontend:** Responsive HTML/CSS (Phone Friendly)
- **Hosting:** Render/PythonAnywhere (Upcoming)
